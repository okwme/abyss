# Store listing

## Title

abyss, an unofficial Telegram client

## Subtitle

Look in. Nothing looks back.

## Short description

A quiet macOS messaging client. Telegram first. Links in messages are copied, media stays a labelled chip. Not yet available to download.

## Full description

A quiet, hardened window onto the networks you message on. Telegram first.

Links in messages are copied, never opened.

Media is shown as a labelled chip. Nothing is downloaded or decoded in this version.

The message cache on disk is encrypted with a key that stays in this Mac’s Keychain. Signing out destroys the key first, then the files.

abyss tells you when it is not sure a message was sent.

You choose a hue and how much of it, separately for night and day. Lightness is fixed, so text stays readable.

Old conversations sink. The list darkens with age, so you can see what is stale without reading dates.

Telegram’s servers can still read cloud chats. There are no secret chats, calls, stickers, browser or Mini Apps in this version.

abyss is macOS only. It is not yet available to download.

abyss is an unofficial Telegram client. It uses the Telegram API.

## What's not in this version

- Secret chats
- Calls
- Stickers
- Browser
- Mini Apps
- Media downloads or decoding
- Platforms other than macOS
- A public download
