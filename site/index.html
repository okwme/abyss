abyss

Look in. Nothing looks back.

A quiet, hardened window onto the networks you message on. Telegram first.

macOS only. Not yet available to download.

Surface

Message links are copied.

Links in messages are copied, never opened.

Shallows

A label for media.

Media is shown as a labelled chip. Nothing is downloaded or decoded in this version.

Mid water

The key stays on this Mac.

The message cache on disk is encrypted with a key that stays in this Mac’s Keychain. Signing out destroys the key first, then the files.

Deep

“Not sure it was sent.”

abyss tells you when it is not sure a message was sent.

Trench

You choose the colour.

Pick a hue and how much of it, separately for night and day. Lightness is fixed, so text stays readable.

Floor

Old conversations sink.

The list darkens with age, so you can see what is stale without reading dates.

The limits, plainly.

Telegram’s servers can still read cloud chats.

There are no secret chats, calls, stickers, browser or Mini Apps in this version.

abyss is macOS only. It is not yet available to download.

abyss is an unofficial Telegram client. It uses the Telegram API.
